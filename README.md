# ApexSide website

A responsive, black-and-green, multi-page business website built with plain HTML, CSS and JavaScript. No paid services, frameworks or build tools are needed.

## Preview locally

Open `index.html` in Chrome, Edge, or Firefox. Use the navigation to browse the other pages.

## Included

- Home / Ideas / Tools / Free guide / About / Contact / Disclosures
- Mobile menu and accessible navigation
- Filterable side-hustle ideas
- Working income estimator (USD, illustrative only)
- Working idea matcher
- Downloadable seven-day checklist
- SVG branding / favicon

## Before publishing

1. Contact email is set to `abdishakurmh@hotmail.com` in `contact.html`. The form opens the visitor's email application; it does not send messages automatically.
2. Replace demo wording, add original verified content and actual business details.
3. Review disclosures, consumer-law requirements, tax rules and privacy laws applicable to your location.
4. Add real affiliate links only after approval into affiliate programs, clearly disclose commissions, and verify product claims.
5. Do not present the illustrative dashboard as actual revenue or testimonials.
6. Consider getting a domain and adding a secure form backend/email platform if needed.

## Publish free with GitHub Pages

1. Create a GitHub repository, e.g. `apexside`.
2. Upload the *contents* of this folder (not the ZIP itself) to the repository root.
3. In repository **Settings → Pages**, select **Deploy from a branch**, branch `main` and folder `/ (root)`, then Save.
4. Your website will be served at `https://YOUR_USERNAME.github.io/apexside/` once deployed.
5. Google indexing is separate from publishing. After launch, use Google Search Console to verify the site and submit a sitemap.

You can also deploy the folder through Netlify Drop or Cloudflare Pages. Check their current free-plan conditions.

## Revenue model

This site is a foundation, not an automatic income machine. Start by publishing unique guides, recommending independently tested tools with affiliate disclosure, and later creating useful digital products. Monetization depends on traffic, trust, conversions, legal compliance and ongoing work.
